## APIs

- **Offendersearch API** — Nationwide sex-offender registry search API offering synchronous, asynchronous, and batch lookups, normalized scored records, per-source provenance, freshness tiers, and consolidated verification-report PDFs. (`https://api.offendersearch.app`)

> Public REST API with a valid OpenAPI 3.1 contract (JSON+YAML) discoverable via RFC 9727 api-catalog at /.well-known/api-catalog. A hosted MCP server is advertised at https://mcp.offendersearch.app exposing tools (search_offenders, batch_search, get_registry_coverage) but is currently private beta / request-access, so it is not treated as an openly reachable MCPServer property; documented here via the /mcp-server Documentation page. agent_native=true is driven by the documented AI tool-calling integration and advertised llms.txt. An llms.txt is advertised at https://offendersearch.app/llms.txt but could not be independently retrieved and is not listed in the provider's api-catalog, so it is omitted from properties. API and MCP access require an API key with mandatory billing; no free tier. No AsyncAPI, GraphQL, or Postman collection found.
